1. Executive Summary & Audit Scope

Rather than relying on happy-path demonstrations, this audit systematically tested the application against empty inputs, garbage text, rapid multi-click submissions, missing social preview tags, and cross-device viewports. All identified high-priority vulnerabilities have been remediated in code.

2. "Where It Breaks" Stress Testing Matrix

Scenario Trigger Action Pre-Hardening Behavior Triage Fix / Remediation Applied
1. Empty Form Clicked Submit with empty inputs Browser default native alert Fix-Now Added input trimming, regex validation, and inline status feedback element.
2. Double Click Clicked Submit twice in < 300ms Sent duplicate HTTP requests Fix-Now Added submit locking (isSubmitting flag) & button disabling.
3. Invalid Email Entered test@ or invalid format Allowed submission / raw alert Fix-Now RFC-compliant email regex validation with user feedback.
4. Space Input Filled name with spaces " " Accepted spaces as valid string Fix-Now Enforced .trim() sanitization across all input fields.
5. Social Meta Link shared on WhatsApp / LinkedIn Blank preview card Fix-Now Injected OpenGraph (og:title, og:image), Twitter Cards & Schema JSON-LD.
6. API Throttling >3 consecutive API calls / sec Temporary HTTP 429 throttling Limitation Documented rate limit behavior with exponential backoff notice.
